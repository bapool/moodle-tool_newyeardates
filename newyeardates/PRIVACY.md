# Privacy and Data Protection

## Data Storage

This plugin does not store any personal data. It only modifies course activity dates based on teacher actions.

## Data Processing

The plugin processes:
- Course start dates (non-personal administrative data)
- Activity due dates and availability dates (non-personal course structure data)

No student information, enrollment data, or personally identifiable information is accessed, stored, or transmitted by this plugin.

## GDPR Compliance

This plugin is GDPR compliant as it does not handle any personal data.
